## Pertemuan 4 — Design Token Halaman Profil

- Berkas gaya yang dibuat: tokens.css, base.css, layout.css, komponen.css, tema.css
- Warna utama: #1D4ED8 (biru)
- Warna dipilih agar tampilan halaman terlihat sederhana dan konsisten.

### Token yang saya tetapkan

| Token | Nilai | Untuk apa |
|---|---|---|
| --color-primary | #1D4ED8 | tombol dan tautan |
| --color-fg | #0F172A | warna teks |
| --color-bg | #F8FAFC | latar halaman |
| --radius-md | 0.5rem | sudut tombol dan kartu |
| --space-4 | 1rem | jarak standar |

Kriteria selesai saya: mengubah --color-primary di satu baris harus mengubah warna komponen yang menggunakan token tersebut.
